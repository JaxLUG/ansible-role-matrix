# JaxLUG™ Ansible Matrix Role

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg?style=plastic)](https://github.com/JaxLUG/ansible-role-matrix/blob/master/LICENSE.txt)

This repository is part of the official Jacksonville, Florida, Jacksonville
Linux Users Group™'s community Ansible Config Project (ACP).

This the JaxLUG™'s ansible role for matrix homeservers using lighttpd and
synapse on Gentoo Linux. This role is assuming usage of a matrix profile from
the [overlaid](https://github.com/wltjr/overlaid) Gentoo overlay.

This is an initial work-in-progress community contribution, anyone is
welcome to participate and/or use.
